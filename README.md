# pairwise-navmesh-repath

门被炸开后 NPC 仍绕远路，动态障碍只改了本地 tile 的通行标记，跨 tile 的边界代价没重算；路径平滑拉直时穿墙，拉直只看端点不看走廊宽度；多个 agent 同时寻路共用一份 scratch，偶尔拿到别人的父节点；寻路预算按固定节点数截断，远距离目标直接失败；传送后最近多边形查询用了旧层，NPC 从错误区域起步；斜坡 link 双向代价不对称，下坡比上坡贵一倍；群体避让把路径点整体推开，推到了不可走区域；导航网格 LOD 切换时 agent 还引用已释放的多边形；异步重建完成前查询返回空，NPC 原地发呆；路径缓存没绑定障碍版本，炸开的门一直不可通行。gameplay/navmesh_repath.py 是核心，tests/test_navmesh_repath.py 15个红。要修的是：障碍更新重算受影响 tile 与边界；拉直做走廊宽度检测；scratch 按 agent 隔离；预算按剩余距离动态分配；传送后按层重建最近多边形；link 代价对称；避让结果投影回网格；LOD 切换迁移 agent 引用；重建期间回退旧网格；缓存带障碍版本号。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
